01什么是 MD5？

MD5（Message Digest Algorithm 5）是由Ronald Rivest 于 1992 年设计的密码散列函数，将任意长度的输入数据压缩为 128 位（16 字节）的固定长度哈希值。它基于 Merkle-Damgård 结构，通过 4 轮共 64 步非线性运算，确保输入的任何微小变化都会导致输出的巨大差异（雪崩效应）。

数据完整性校验

MD5 广泛用于文件校验和、数据指纹，快速检测文件是否被篡改或损坏。

密码存储 (已不推荐)

曾用于存储密码哈希，但因计算速度极快且存在碰撞攻击，已被 Argon2id/bcrypt 替代。

安全缺陷

已发现多种碰撞攻击（2004 年王小云团队），不应用于安全敏感场景。

安全提示
MD5 已被证明存在碰撞攻击和原像攻击的进展，不应用于数字签名、SSL 证书或密码存储等安全场景。本页面仅作算法学习与可视化用途。

04消息填充

MD5 的第一步是将输入消息填充至 512 位的整数倍。填充规则：先追加一个 1 位，再追加 0 位直到长度 ≡ 448 (mod 512)，最后追加 64 位原始消息长度（小端序）。

06四轮非线性函数

MD5 的核心是 4 轮变换，每轮使用不同的非线性函数（F, G, H, I），每轮包含 16 步操作，共 64 步。每步操作都会混合 A, B, C, D 四个寄存器，引用消息字 M[i] 和常量 K[i]。

第 3 轮: H
第 4 轮: I

第 1 轮: F 函数 (步骤 0-15)

使用条件函数 F，对 B, C, D 进行按位逻辑运算。消息字按顺序 M[0..15] 引用。

F(b, c, d) = (b AND c) OR (NOT b AND d)

每步操作:
A = B + ((A + F(B, C, D) + M[g] + K[i]) <<< s)
轮转: (A,B,C,D) → (D, new_A, B, C)

第 2 轮: G 函数 (步骤 16-31)

使用选择函数 G，消息字索引按 (5i+1) mod 16 引用。

G(b, c, d) = (b AND d) OR (c AND NOT d)

每步操作:
A = B + ((A + G(B, C, D) + M[g] + K[i]) <<< s)

第 3 轮: H 函数 (步骤 32-47)

使用奇偶函数 H，消息字索引按 (3i+5) mod 16 引用。

H(b, c, d) = b XOR c XOR d

每步操作:
A = B + ((A + H(B, C, D) + M[g] + K[i]) <<< s)

第 4 轮: I 函数 (步骤 48-63)

使用逻辑函数 I，消息字索引按 (7i) mod 16 引用。

I(b, c, d) = c XOR (b OR NOT d)

每步操作:
A = B + ((A + I(B, C, D) + M[g] + K[i]) <<< s)
常量 K 和移位 S
每步使用一个来自 floor(2^32 × |sin(i+1)|) 的常量 K[i]（共 64 个），以及一个循环左移位数 S[i]。这些常量确保了算法的非线性和雪崩效应。

08安全性分析

MD5 的安全性已严重退化。以下图表对比了 MD5 与现代哈希算法的安全性能。

碰撞攻击

2004 年王小云团队首次发布完整碰撞攻击，可在数小时内找到两个不同输入产生相同 MD5 值。后续改进已将碰撞时间缩短至秒级。

长度扩展攻击

由于 Merkle-Damgård 结构，攻击者可在不知道原始消息的情况下追加数据并计算合法哈希，导致 MD5 不适合用于消息认证。

速度过快

MD5 设计为高速哈希，现代 GPU 每秒可计算数十亿次 MD5，使暴力破解密码变得极其廉价。

现代替代方案

密码存储推荐 Argon2id / bcrypt；通用哈希推荐 SHA-256 / SHA-3；消息认证推荐 HMAC-SHA256。
