⚡ 位运算
直接对二进制位进行操作，包括与、或、异或、移位等，常用于状态压缩和高效计算。
时间: O(1) 空间: O(1)
点击展开详情

常用技巧

  • n & 1 判断奇偶
  • n ^ n = 0 异或去重
  • n & (n-1) 消除最低位的1（判断2的幂）
  • 1 << k 生成第k位掩码

示例：只出现一次的数字

int singleNumber(int[] nums) { int result = 0; for (int num : nums) { result ^= num; // 异或去重 } return result; }

核心算法

  • 辗转相除法(GCD)：O(log n)

  • 埃氏筛：O(n log log n) 筛素数
  • 欧拉筛：O(n) 线性筛素数

示例：快速幂

long fastPow(long base, long exp, long mod) { long result = 1; while (exp > 0) { if ((exp & 1) == 1) result = result * base % mod; base = base * base % mod; exp >>= 1; } return result; }

经典算法

  • Fisher-Yates 洗牌：O(n) 生成均匀随机排列
  • 蓄水池抽样：从未知大小数据流中随机选取 k 个
  • 蒙特卡洛：用随机采样近似求解

示例：蓄水池抽样

int[] reservoirSample(int[] stream, int k) { int[] reservoir = new int[k]; for (int i = 0; i < k; i++) reservoir[i] = stream[i]; Random rand = new Random(); for (int i = k; i < stream.length; i++) { int j = rand.nextInt(i + 1); if (j < k) reservoir[j] = stream[i]; } return reservoir; }

时间: O(n) 空间: O(n)

解题要点

  • 仔细阅读题意，确定模拟规则
  • 注意边界条件和特殊情况
  • 合理选择数据结构（数组、队列、栈等）
  • 常见场景：螺旋矩阵、生命游戏、约瑟夫环

示例：螺旋矩阵遍历

List<Integer> spiralOrder(int[][] matrix) { List<Integer> res = new ArrayList<>(); int top = 0, bottom = matrix.length - 1; int left = 0, right = matrix[0].length - 1; while (top <= bottom && left <= right) { for (int i = left; i <= right; i++) res.add(matrix[top][i]); top++; for (int i = top; i <= bottom; i++) res.add(matrix[i][right]); right--; if (top <= bottom) { for (int i = right; i >= left; i--) res.add(matrix[bottom][i]); bottom--; } if (left <= right) { for (int i = bottom; i >= top; i--) res.add(matrix[i][left]); left++; } } return res; }
🔀 分治算法
将问题分解为子问题分别求解，再合并结果。经典应用包括归并排序、快速排序、最近点对等。
时间: O(n log n) 空间: O(log n)
点击展开详情

三步法

  • 分解：将问题拆为规模更小的子问题
  • 解决：递归求解子问题（足够小时直接求解）
  • 合并：将子问题的解组合为原问题的解

示例：归并排序

void mergeSort(int[] arr, int left, int right) { if (left >= right) return; int mid = left + (right - left) / 2; mergeSort(arr, left, mid); mergeSort(arr, mid + 1, right); merge(arr, left, mid, right); }
🪟 滑动窗口
维护一个窗口在数组/字符串上滑动，高效解决连续子序列问题，避免重复计算。
时间: O(n) 空间: O(k)
点击展开详情

适用场景

  • 固定窗口：窗口大小不变
  • 可变窗口：窗口大小动态调整
  • 经典题目：最长无重复子串、最小覆盖子串、滑动窗口最大值

示例：最长无重复字符子串

int lengthOfLongestSubstring(String s) { Map<Character, Integer> map = new HashMap<>(); int maxLen = 0, left = 0; for (int right = 0; right < s.length(); right++) { char c = s.charAt(right); if (map.containsKey(c)) left = Math.max(left, map.get(c) + 1); map.put(c, right); maxLen = Math.max(maxLen, right - left + 1); } return maxLen; }
📊 前缀和与差分
预处理数组实现区间求和（前缀和）或区间更新（差分），将 O(n) 操作降为 O(1)。
预处理 O(n), 查询 O(1) 空间: O(n)
点击展开详情

前缀和公式

  • prefix[i] = arr[0] + arr[1] + ... + arr[i-1]
  • 区间和 sum(l, r) = prefix[r+1] - prefix[l]

差分公式

  • 区间 [l,r] 加 val：diff[l] += val; diff[r+1] -= val;
  • 还原：对 diff 做前缀和得到修改后的数组

示例：前缀和

int[] prefix = new int[n + 1]; for (int i = 0; i < n; i++) prefix[i + 1] = prefix[i] + arr[i]; // 查询 [l, r] 的区间和 int rangeSum = prefix[r + 1] - prefix[l];
📋 枚举算法
遍历所有可能的情况寻找解，简单直接。通过剪枝优化可大幅减少搜索空间。
时间: O(n^k) 空间: O(1)
点击展开详情

优化策略

  • 剪枝：提前终止不可能产生解的分支
  • 减少枚举变量：利用约束关系减少循环层数
  • 枚举顺序：选择有利顺序提前命中或排除

示例：两数之和（枚举法）

int[] twoSum(int[] nums, int target) { for (int i = 0; i < nums.length; i++) { for (int j = i + 1; j < nums.length; j++) { if (nums[i] + nums[j] == target) return new int[]{i, j}; } } return new int[]{}; }
