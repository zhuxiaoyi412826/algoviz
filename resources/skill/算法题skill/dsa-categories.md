# 数据结构与算法分类参考

> 本文件提供基础分类框架。详细的题目索引和多解法参考请查阅 [book-reference.md](book-reference.md)。

## 数据结构

### 线性结构
- **数组**：双指针、滑动窗口、前缀和、差分数组、矩阵操作、原地操作（标记法、翻转法）、区间合并
- **链表**：虚拟头节点、快慢指针、递归操作、区间翻转、K组反转、合并/拆分、环检测、LRU/LFU 缓存
- **栈**：括号匹配、单调栈（Next Greater Element、柱状图、每日温度）、表达式求值、辅助栈（最小栈）、双栈模拟
- **队列**：单调队列（滑动窗口最大值）、优先队列（Top K）、双端队列、双栈模拟队列

### 树形结构
- **二叉树**：遍历（前中后/层序/锯齿形）、路径和问题、LCA、序列化/反序列化、直径、翻转、合并、子树统计
- **二叉搜索树**：验证BST、第K小/大元素、插入/删除/查找、BST转Greater Tree、修剪BST
- **Trie（字典树）**：标准Trie、带通配符搜索、0-1 Trie（最大异或）、前后缀搜索
- **堆**：Top K 问题、合并 K 个有序序列、中位数维护、双堆（滑动窗口中位数）
- **线段树**：区间求和、区间最值、动态开点、扫描线（天际线问题）
- **树状数组（BIT）**：前缀和查询、逆序对计数、区间和统计
- **ST 稀疏表**：静态区间最值查询（RMQ）、稀疏表构建与查询
- **跳表**：跳表设计与实现、多层索引结构
- **平衡树思想**：AVL 树旋转、红黑树性质、B+树结构（概念与性质为主）

### 图结构
- **图的遍历**：BFS（最短路径、多源BFS）、DFS（连通分量、回溯搜索）
- **最短路径**：Dijkstra、Bellman-Ford、Floyd、SPFA
- **最小生成树**：Kruskal、Prim
- **拓扑排序**：课程表问题、任务调度、BFS入度法/DFS后序
- **二分图**：BFS/DFS着色判定
- **连通分量**：无向图连通分量、有向图强连通分量（Tarjan）
- **Tarjan 算法**：强连通分量（SCC）、割点、割边
- **欧拉路径**：重建行程、Hierholzer 算法
- **图的克隆**：深拷贝图结构

### 高级数据结构
- **哈希表**：两数之和、字母异位词、最长连续序列、前缀和+HashMap、设计HashMap/HashSet
- **并查集**：路径压缩+按秩合并、连通分量计数、带权并查集、冗余连接、账户合并

## 算法

### 排序与搜索
- **排序**：快速排序（三路划分）、归并排序（链表排序、逆序对）、堆排序、计数/桶排序、基数排序、自定义比较器
- **二分查找**：标准模板（4种变体）、旋转数组搜索、搜索区间、峰值查找、二分答案（吃香蕉、运输包裹）
- **快速选择**：第K大/小元素（BFPRT优化）
- **离散化**：坐标压缩、值域映射、去重排序

### 动态规划
- **一维 DP / Fibonacci型**：爬楼梯、打家劫舍（线性+环形+树形）、股票买卖系列（6题）、最长递增子序列
- **二维 DP / 矩阵DP**：矩阵路径（最小和、唯一路径）、编辑距离、最长公共子序列（LCS）、最大正方形、01矩阵
- **背包问题**：0-1 背包（等分_subset_sum、目标和）、完全背包（零钱兑换、组合总和IV）、多重背包
- **背包DP优化**：滚动数组、一维压缩、分组背包
- **字符串 DP**：正则匹配、通配符、解码方法、最长回文子序列
- **区间 DP**：戳气球、合并石子、超级蛋掉落
- **状态机 DP**：股票系列（含冷冻期、含手续费）、132模式
- **树形 DP**：二叉树的直径、打家劫舍III、子树统计

### 贪心算法
- **区间调度**：活动选择、无重叠区间、射气球
- **跳跃问题**：跳跃游戏 I/II
- **排序+贪心**：分配饼干、重建队列、分发糖果（两次遍历）
- **字符串贪心**：字典序最小、拼接最大数、分割标签
- **哈夫曼编码**：最优前缀编码、合并果子

### 回溯与分治
- **排列组合**：全排列（去重）、子集（去重）、组合总和（多种变体）
- **棋盘问题**：N 皇后（位运算优化）、解数独、单词搜索
- **分割问题**：回文分割、IP地址还原、加法数
- **分治**：合并 K 个链表、最大子数组、不同方式加括号、Beautiful Array 构造

### 字符串算法
- **模式匹配**：KMP、Rabin-Karp（滚动哈希）
- **回文串**：Manacher算法（O(n)最长回文子串）、中心扩展（4种解法）、回文分割、回文子串计数
- **滑动窗口**：最小覆盖子串、无重复最长子串、字母异位词、排列子串（数组+字符串通用）
- **字符串DP**：编辑距离、正则匹配、解码方法

### 数学与位运算
- **数学**：GCD/LCM、快速幂、质数筛、进制转换、拒绝采样、Fisher-Yates 洗牌
- **位运算**：XOR（只出现一次的数字系列）、位计数、幂集、位掩码（单词长度乘积）、lowbit

### 设计类
- **缓存设计**：LRU Cache（HashMap+双向链表）、LFU Cache（频率链表+HashMap）
- **随机化设计**：Rand10() from Rand7()、带权随机、洗牌算法
- **集合设计**：O(1)插入删除随机、全O(1)数据结构
- **数据流设计**：滑动窗口中位数、数据流 Top K、在线统计
- **限流结构**：令牌桶、漏桶算法、频率限制器

## 常见出题模式

### 模式一：直接求解
给定输入，直接计算输出。考察对数据结构的直接操作能力。

### 模式二：变体经典题
在经典题基础上修改条件或约束。考察对算法本质的理解。

### 模式三：多步骤组合
需要先用一种算法预处理，再用另一种算法求解。考察综合运用能力。

### 模式四：设计类
设计一个数据结构或系统，满足特定的操作和时间复杂度要求。考察系统设计思维。

### 模式五：实际场景
将算法包装在实际应用场景中（如任务调度、路径规划等）。考察建模能力。
